## Coverage and limitations

All local migration filenames were inventoried and structural declarations searched across the migration set, including early LMU/admin tables and late assessment seeds. High-risk release, authority, enrollment, storage, movement and privacy paths received targeted source reading. This is not a formal proof of every SQL branch or every endpoint. The local schema is migration intent; additive reconciliation migrations can preserve preexisting deployed objects. No deployed ledger, grants, indexes, query plans or data were inspected.

The baseline course is the general-builder course described in the assignment. Hub Leader Cohort is supported by local import documentation and a runtime-specific navigation branch (`lib/experiences/builder/progress-mutations.ts:129–134`); its exact current content/state was not verified. Import documentation counts are historical proposals, not current database counts. Kaleo importer scripts exist, but no external curriculum archives were opened and no full 32-week content inventory is asserted.

The older `docs/performance-assessment-2026-10-02.md` was read as historical context, not accepted as current evidence. Its whole-page chat polling, per-card full resolver and unbatched display-signing findings have changed in the current source (F18–F19 and `components/experiences/builder/PrebuiltAssessmentBlock.tsx:13–34`). Its live observations were not reproduced and are not measurements for this audit.

No network calls, Supabase requests, servers, builds, tests, CLI migrations, deployments or application code changes were performed during this audit. No `.env*` or secret files were opened. Only the eight requested Markdown reports were created.
